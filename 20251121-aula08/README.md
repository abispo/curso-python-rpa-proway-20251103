# PyautoGui

O **PyAutoGUI** é um módulo Python de código aberto que permite a automação de interface gráfica (GUI) e controle programático do mouse e teclado.

* **O que faz**: Ele simula interações humanas, como mover o mouse, clicar, digitar textos e pressionar teclas. É amplamente usado para tarefas de automação repetitivas, testes automatizados de software e até mesmo jogos simples.

* **Vantagem**: Permite que seu script interaja com qualquer aplicativo ou sistema operacional (Windows, macOS, Linux) ao controlar a tela visualmente, sem depender de APIs específicas de aplicativos.

Acesse [a documentação oficial](https://pyautogui.readthedocs.io/en/latest/) do PyAutoGui.

# Telegram Bot

Um **Telegram Bot** é uma conta de usuário automatizada que pode interagir com usuários, grupos e canais dentro do aplicativo de mensagens Telegram.

* **Como funciona**: Ele utiliza a API do Bot do Telegram (uma API HTTP simples) para enviar e receber mensagens e eventos. O bot é controlado por um código hospedado em um servidor externo.

* **Aplicações**: Variam desde a automação de tarefas simples (como enviar notificações, previsão do tempo ou cotações) até a criação de jogos e ferramentas interativas. A biblioteca Python mais comum para isso é a [`python-telegram-bot`](https://python-telegram-bot.org/).

# Whatsapp bot com Baileys

O **Baileys** é uma biblioteca Node.js de código aberto que implementa o protocolo **Multi-Device do WhatsApp**.

* **O que é**: É uma das ferramentas mais populares para criar **WhatsApp Bots** (também chamados de "*unofficial*" ou "*self-hosted*"), permitindo que você envie, receba e processe mensagens diretamente usando o WhatsApp Web/Desktop como base de conexão.

* **Observação importante**: Diferente da **API Oficial do WhatsApp Business** (que é paga e controlada pelo Meta), o Baileys é focado em fornecer uma interface de programação de baixo nível para as funcionalidades do WhatsApp, sendo tipicamente usado em projetos de automação pessoal ou para pequenos negócios.

* **Uso**: É ideal para construir chatbots personalizados que podem responder automaticamente a consultas ou gerenciar fluxos de conversação complexos.
